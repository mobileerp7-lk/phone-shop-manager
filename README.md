# Phone Shop Manager

A free, open Android app for running a mobile phone shop: products and stock (with IMEI), selling (POS), repairs, purchases, customers and suppliers, money accounts, expenses, and reports with profit and loss.

It is a template: shop name, currency, tax and product categories are set inside the app. Each shop keeps its own data, either on the phone only or in its own Supabase project.

Status: planning. See [PLAN.md](PLAN.md) for the plan and `docs/wireframe/` for the screen designs (source of the published wireframe). No app code yet.
